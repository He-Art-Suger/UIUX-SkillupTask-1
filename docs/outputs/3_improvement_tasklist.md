## 3.タスク一覧ページの改善
今回はUIUXのスキルアップが主目的のため。UIUXに対する課題の解決を中心とし、機能の追加はあまり行わない。

### TASK.mdからの要求
**必須改善：**
- 追加機能
    [] 検索機能
    [] ステータスによる絞り込み
    [] (空状態)
- UX向上
    [] 優先度・期限・状態が視覚的に分かるUIにする
    [] (スマホ表示を改善する)

**発展改善：**
- 追加機能
    [] 並び替え
- UX向上
    [] 期限が近いタスクを強調する
    [] タスクカードをより再利用しやすい構造にする(コンポーネント設計)

### 自分で追加した改善
- UX向上
    [] カード全体が詳細への画面遷移リンクになるようにする
    [] 優先度に応じて3列にし、列を色分けする(優先度高の幅を広くできるといいかも)

### 作業の流れ
1. 画面デザイン設計
    - 論理的、根拠が説明できるようなUI設計(そのうえで主観もエッセンスとして混ぜる)
    - DESIGN.mdを作成しデザイン設計の方針を固める
    - Figmaで画面デザインを考案
    - Google Stitch も利用したい
2. 追加機能実装
3. デザイン・フロントエンドへの落とし込み
    - Storybook によるUIテスト


### 使用するツール・概念
- Figma
- Google Stitch
- Storybook
- DESIGN.md
